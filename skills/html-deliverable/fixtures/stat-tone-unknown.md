# A stat card asking for a tone that is not a tone

Built with an unknown tone, this file is REFUSED rather than published:

    build.py fixtures/stat-tone-unknown.md out.html --stat "47 | pages built | green"

The tone field takes one letter: g for money and act-now, a for caution, r for risk, n for
context. Writing the word used to render a context-colored card in silence, so the author read
their own intent back off the page and never learned it had been dropped. The same build with
`| g` succeeds.
